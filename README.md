# Human-Written vs AI-Generated Text Detection Using BiLSTM and Word2Vec

## Overview

The rapid growth of Large Language Models (LLMs) has made it increasingly difficult to distinguish between human-written and AI-generated text. This project presents a deep learning approach for identifying whether a given piece of English text was written by a human or generated by an AI model.

The system is built using a Bidirectional Long Short-Term Memory (BiLSTM) network combined with Word2Vec embeddings to capture contextual and sequential patterns in text. Users can enter any English paragraph through a simple Streamlit interface and receive an instant prediction along with the model's confidence score.

- Deep learning model based on BiLSTM

## Model Architecture

The model follows the sequence below:

- Text Cleaning
- Tokenization
- Sequence Padding
- Word2Vec Embedding Layer
- Bidirectional LSTM
- Dense Layer
- Sigmoid Output Layer

## Limitations

- Designed primarily for English text.
- Performance is strongest on paragraph and essay-style writing.
- Highly technical documents, slightly doesn't impact on OCR text, or fragmented content may produce lower confidence predictions.
